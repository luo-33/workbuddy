🔄 数据库迁移指南

📌 当前所有数据存储在浏览器本地存储（localStorage）中，导出文件可直接用于迁移到后端数据库。

迁移步骤：

  1. 点击「导出全部数据」下载 JSON 文件
  2. 部署后端 API 服务（Node.js / Python / 云函数）
  3. 修改 DB.get/set 实现为 fetch 请求（见下方代码示例）
  4. 上传 JSON 数据到新数据库
// 迁移后的 DB 实现示例
const DB = {
  async get(key, def=null) {
    const res = await fetch('/api/data/'+key);
    return res.ok ? await res.json() : def;
  },
  async set(key, val) {
    await fetch('/api/data/'+key, {
      method: 'POST',
      body: JSON.stringify(val)
    });
  }
};
